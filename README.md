# Movie Review Sentiment Analysis - Main Branch Update

## Project Description
This Python project uses Natural Language Processing (NLP) and Machine Learning to classify movie reviews as positive or negative.

## Technologies Used
- Python
- Pandas
- Hugging Face Datasets
- TF-IDF
- Logistic Regression
- Scikit-learn

## Dataset
IMDb Movie Reviews Dataset

## How to Run
1. Open the project in Google Colab.
2. Install the required libraries.
3. Run the code to preprocess the dataset.
4. Train the Logistic Regression model.
5. Evaluate the model using a Classification Report and Confusion Matrix.
6. Test the model with a custom movie review.

## Note
The project was originally developed in Google Colab and requires adjustments before running as a standard Python script in PyCharm.
